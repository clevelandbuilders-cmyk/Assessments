Patio Door Replacement
Patio Door
Pella Lifestyle Series Hinged Patio Door

We'll remove your existing two-panel patio door and install a new Pella Lifestyle Series hinged patio door in the same opening. The new door keeps the layout you're used to: one fixed panel and one operating panel that swings into the room, hinged at the center.

Remove existing patio door and screen
Install new Pella Lifestyle hinged patio door, sized to the existing opening
Left panel operates and swings inward (as viewed from the deck); right panel is fixed
Insulate, flash, and seal the new unit
Haul away the old door and job debris
