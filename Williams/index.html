Raise Ceiling Ties
Garage · 2045 Cotton Tail Lane
Raise the Ceiling Ties 18" for a Swing Pocket

The heavy ceiling ties in your garage do an important job: they sit on the top of the side walls and tie them together, so the weight of the roof doesn't push the walls outward. Right now there are only a few of them, sitting about 9 ft off the floor, which is right where a golf swing needs room. We'll install new 2x8 ties on every rafter, 18" higher than the existing ones, fastened to the rafters with heavy nailing at each end. Once the new ties are in, the old low ties come out and the ceiling opens up for your swing.

Install 13 new 2x8 x 20 ft ties, one on every rafter, raised 18" above the current ties
Fasten each end to the rafter with extra nailing for the raised height
Remove the existing low ceiling ties and the posts that run from them up to the ridge, once the new ties are in place
Take down and set aside items hanging from the old ties (overhead storage rack and hooks) so the work area is clear
Garage door opener stays and is reattached as needed
Building permit from Brookfield; if they require an engineer's letter for the raised ties, we'll coordinate it
Haul away the old lumber and clean up

Garage · Electrical
Wiring, Opener Outlet & Shop Lights

The existing wiring runs in metal conduit fastened along the old ceiling ties, so it has to come down when the ties come out. The plan is to replace those runs with new Romex cable routed along the new framing, with one ceiling outlet that serves the garage door opener, the radon fan and the new lights. New LED shop lights will brighten the hitting area. Electrical work will be done by a licensed electrician; Dan will reach out to him directly and coordinate the timing with the framing work.

Remove the conduit runs attached to the old ties
Run new Romex along the new framing
New ceiling outlet for the garage door opener; the same circuit also feeds the radon fan and the new lights
Install 4 LED shop lights from Menards, about 5,000 lumens each
Final layout and outlet protection per the electrician and Brookfield code
